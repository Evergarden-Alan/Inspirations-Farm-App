# 任务优先级使用指南

## 功能概述

任务优先级让你更高效地管理日常任务，与灵感优先级形成统一体系。

### 优先级等级

- **P0** 🔴 — 紧急重要（今天必须完成）
- **P1** 🟡 — 重要不紧急（本周完成）
- **P2** 🔵 — 一般任务（默认）
- **P3** ⚪ — 不重要（有空再做）

---

## 使用方法

### 1. 添加带优先级的任务

在「今日耕作」卡片底部：

1. 输入任务内容
2. 选择优先级（P0/P1/P2/P3）
3. 点击 ➕ 或按 Enter 添加

**默认优先级**: P2（一般）

### 2. 优先级标记显示

任务列表中：
- **P0** — 红色标记
- **P1** — 琥珀色标记
- **P2** — 无标记（默认值）
- **P3** — 灰色标记

```
○ 修复登录 bug [P0]           ← 红色
○ 实现代码高亮 [P1]           ← 琥珀色
○ 普通任务                   ← 无标记
○ 更新文档 [P3]               ← 灰色
```

### 3. 子任务优先级继承

子任务自动继承父任务优先级：

```
○ 完成项目报告 [P0]
  ○ 收集数据（继承 P0）
  ○ 撰写分析（继承 P0）
```

## Markdown 格式

### 基本语法

在任务行尾添加 `#p0` / `#p1` / `#p2` / `#p3`：

```markdown
## 当日日程

- [ ] 修复登录 bug #p0
- [ ] 实现代码高亮 #p1
- [ ] 普通任务
- [ ] 更新文档 #p3
```

### 与灵感链接结合

```markdown
- [ ] [[1735123456|查看灵感]] 完成设计 #p0
- [ ] [[1735123789|技术方案]] 评审代码 #p1
```

### 子任务优先级

```markdown
- [ ] 完成项目报告 #p0
  - [ ] 收集数据
  - [ ] 撰写分析
  - [ ] 制作图表 #p1
```

**规则**:
- 子任务未指定优先级 → 继承父任务
- 子任务显式指定优先级 → 覆盖继承

**时间分配**: 紧急任务优先，弹性任务灵活安排

**切换策略**: 完成高优先级任务再切换项目

## 最佳实践

### 1. 优先级设置原则

| 优先级 | 判断标准 | 占比建议 |
|-------|---------|---------|
| **P0** | 今天不做会有严重后果 | 10-20% |
| **P1** | 重要但可以稍晚完成 | 30-40% |
| **P2** | 正常工作任务 | 40-50% |
| **P3** | 有空再做，不做也行 | 10-20% |

**避免**: 所有任务都标记 P0（失去优先级意义）

### 2. 每日回顾

**早晨规划**:
1. 列出所有任务
2. 标记优先级
3. 估算时间

**晚间复盘**:
1. P0 任务是否完成？
2. P1 任务完成多少？
3. 未完成任务是否需要调整优先级？

### 3. 时间分配建议

```
上午（精力最佳）: P0 任务
下午（精力中等）: P1 任务
晚上（精力较低）: P2/P3 任务
```

### 4. 紧急情况处理

**新增紧急任务**:
1. 立即添加并标记 P0
2. 暂停当前任务
3. 处理紧急任务
4. 回顾其他任务优先级

## 与灵感优先级的关系

### 优先级一致性

| 灵感优先级 | 推送到任务 | 建议任务优先级 |
|-----------|-----------|---------------|
| P0 灵感 | → 任务 | P0（立即执行）|
| P1 灵感 | → 任务 | P1（本周执行）|
| P2 灵感 | → 任务 | P2（正常安排）|
| P3 灵感 | → 任务 | P3（有空再做）|

### 转换策略

**从灵感到任务**:
1. 查看高优先级灵感（P0/P1）
2. 点击「推送到今日」
3. 任务自动继承灵感优先级（未来功能）
4. 根据实际情况调整

## 常见问题

### Q: P2 任务为什么不显示标记？
A: P2 是默认优先级，不显示标记以保持界面简洁。

### Q: 如何批量修改任务优先级？
A: 目前需要手动编辑 Markdown 文件，批量修改功能在规划中。

### Q: 子任务一定继承父任务优先级吗？
A: 不一定。子任务可以显式指定优先级覆盖继承。

### Q: 优先级会影响任务排序吗？
A: 目前不会自动排序，保持用户编写的顺序。排序功能在规划中。

### Q: 完成的任务还显示优先级吗？
A: 是的，优先级标记会保留，方便回顾任务重要性。

### Q: 可以添加自定义优先级吗？
A: 目前只支持 P0-P3 四级，与灵感优先级保持一致。

### Q: 如何快速设置优先级？
A: 添加任务时点击对应的优先级按钮（P0/P1/P2/P3）。

## 技术细节

### Markdown 存储格式

```markdown
---
date: 2026-07-27
---

# 当日日程

## 任务

- [ ] 任务 A #p0
- [ ] 任务 B #p1
- [ ] 任务 C
- [ ] 任务 D #p3
  - [ ] 子任务 D1
  - [ ] 子任务 D2 #p0
```

### 优先级提取规则

1. 匹配行尾的 `#p[0-3]` 标记
2. 提取优先级值
3. 移除标记，保留任务文本
4. 子任务继承父任务优先级（如未显式指定）

### 兼容性

- ✅ 与灵感链接兼容
- ✅ 与现有任务兼容（默认 P2）
- ✅ 与其他 Markdown 编辑器兼容（忽略 #p0 标记）
